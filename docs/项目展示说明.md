# 智联校园多维管理平台展示说明

## 一、项目简介

`智联校园多维管理平台` 是一个面向校园场景的综合管理系统，主要用于帮助学校更高效地完成日常管理工作。系统围绕校园常见业务进行设计，能够对人员、班级、考勤、评分、通知等内容进行统一管理，同时支持 AI 辅助交互，提升使用体验和操作效率。

该项目采用前后端分离架构开发，适合用于项目展示、课程设计、比赛答辩、功能演示和本地部署运行。

## 二、项目定位

本项目的核心目标是解决校园管理中常见的几个问题：

- 人员信息分散，管理不统一
- 班级、部门、成员关系维护繁琐
- 考勤、评分等记录依赖人工整理，效率较低
- 通知发布渠道分散，信息传达不及时
- 不同角色可操作的功能边界不够清晰

因此，系统以“统一管理、清晰权限、便捷操作、易于展示”为出发点，构建了一套适合学校日常管理使用的综合平台。

## 三、主要功能

### 1. 人员管理
系统支持对学生、教师、家长及其他校园人员进行统一维护，可录入和管理基础信息，并支持后续权限分配与身份区分。

### 2. 班级管理
支持班级信息维护、成员关联、班主任配置等操作，方便学校进行班级结构化管理。

### 3. 部门与组织管理
可用于维护学校内部的组织结构，帮助系统建立更清晰的人员归属关系。

### 4. 考勤管理
支持考勤记录的录入、查看与管理，方便对学生或相关人员的日常出勤情况进行统计。

### 5. 评分管理
支持个人评分、小组评分等业务场景，可用于日常评价、班级量化管理或活动评分记录。

### 6. 通知管理
支持发布和查看通知公告，便于学校、班级或相关管理人员及时传达信息。

### 7. 权限控制
系统支持角色权限管理，不同用户登录后可看到不同菜单和功能，实现按角色显示、按权限开放。

### 8. AI 辅助功能
系统集成了 AI 对话能力，用户可以通过自然语言方式获取信息或辅助完成部分操作。AI 功能同样受权限控制，不能越权执行指令。

## 四、项目特色

### 1. 贴近校园实际场景
项目功能围绕学校管理的真实需求展开，具有明确的应用背景，便于展示其实际价值。

### 2. 权限驱动设计清晰
系统强调“谁能看什么、谁能做什么”，不同身份进入系统后展示不同内容，逻辑清楚，适合答辩展示。

### 3. 前后端分离，结构清晰
前端负责页面展示与交互，后端负责业务处理与数据管理，整体结构规范，便于维护和扩展。

### 4. 具备工程化能力
项目不仅包含业务功能，还具备数据库迁移、打包发布、权限模板初始化等工程化内容，更接近真实项目形态。

### 5. 具备扩展空间
当前系统已覆盖校园管理核心模块，同时预留 AI、权限模板、部署发布等扩展方向，后续可继续完善。

## 五、适用展示场景

本项目适合用于以下场景：

- 学校信息化相关项目展示
- 课程设计与毕业设计展示
- 编程类、创新类、计算思维类比赛作品展示

## 六、技术实现概述

### 前端技术
- Vue 3
- TypeScript
- Vite
- Element Plus
- Pinia
- Vue Router

### 后端技术
- Rust
- Axum
- SQLx
- PostgreSQL
- JWT 身份认证

## 七、系统运行方式

项目默认采用本地开发与本地部署方式运行：

- 前端开发地址：`http://localhost:3001`
- 后端服务地址：`http://localhost:3000`
- 默认数据库：`PostgreSQL`

系统支持数据库迁移初始化，并可通过脚本进行打包整理，方便在展示电脑上运行。

## 八、展示时可重点介绍的内容

在对外展示本项目时，可以重点说明以下几点：

1. 这是一个面向校园场景的综合管理平台。
2. 系统覆盖人员管理、班级管理、考勤管理、评分管理、通知管理等核心业务。
3. 系统采用权限控制机制，不同身份用户看到的功能不同。
4. 系统支持 AI 对话辅助，但 AI 仍然遵守权限边界。
5. 项目使用 Vue 3 + TypeScript + Rust + PostgreSQL 实现，兼顾界面体验与系统稳定性。
6. 项目具备较完整的工程化能力，包括数据库迁移、部署说明和发布目录整理。

## 九、总结

`智联校园多维管理平台` 是一个兼顾实用性、展示性和扩展性的校园综合管理系统。它不仅能够完成校园常见业务管理，还通过权限控制与 AI 辅助能力提升了系统的完整度和亮点。无论用于课程展示、作品答辩还是功能演示，都具有较好的表达效果和实际价值。
