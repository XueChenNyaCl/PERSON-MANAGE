# 打包发布说明（Windows）

## 一键脚本

已新增脚本：`scripts/build_release.bat`

作用：
- 构建前后端（执行 `npm run build`）
- 整理发布目录到 `newnewnew`
- 覆盖复制后端可执行文件、迁移脚本、权限模板
- 如根目录存在 `.env`，会同步复制到发布目录

---

## 使用步骤

在项目根目录执行：

`scripts\build_release.bat`

执行成功后，发布目录为：`newnewnew`

关键产物：
- `newnewnew/school-management-backend.exe`
- `newnewnew/migration.exe`
- `newnewnew/static/`（前端静态资源）
- `newnewnew/migrations/`
- `newnewnew/templates/permissions/`

---

## 发布运行建议

1. 先执行数据库迁移：运行 `newnewnew\migration.exe`
2. 再启动后端服务：运行 `newnewnew\school-management-backend.exe`
3. 默认监听端口：`SERVER_PORT`，未配置时为 `3000`

---

## 注意事项

- 若脚本提示构建失败，请先在源码中修复编译错误后重试。
- 若发布环境端口冲突，请在 `.env` 中调整 `SERVER_PORT`。
- 前端产物由后端托管，发布时只需部署 `newnewnew` 目录即可。
