# 项目讲解提词

## 引言
大家好，今天我要为大家讲解这个项目。这是一个基于Rust后端和Vue.js前端的全栈教育管理系统，集成了AI功能，用于人员管理、班级管理、权限控制等。项目结构清晰，包含后端、前端、数据库和文档等部分。接下来，我将从项目概述开始，逐步讲解各个组件，并进行演示。

## 项目概述
- **项目名称**：（根据实际情况填写，或简称为“教育管理系统”）
- **技术栈**：
  - 后端：Rust（使用Actix-web框架）
  - 前端：Vue.js + TypeScript + Vite
  - 数据库：PostgreSQL
  - AI集成：支持AI模型调用和Markdown输出适配
- **主要功能**：
  - 用户登录和权限管理
  - 人员管理（添加、编辑、删除用户）
  - 班级管理（创建班级、分配人员）
  - AI功能（智能问答、内容生成）
  - WebSocket支持实时通信
- **项目结构**：
  - backend/：Rust后端代码
  - frontend/：Vue.js前端代码
  - docs/：文档和说明
  - support/：PostgreSQL数据库支持
  - model/：AI模型相关文件

## 后端讲解（Rust）
- 后端位于backend/文件夹，使用Cargo.toml管理依赖。
- 主要模块：
  - src/main.rs：入口文件
  - src/api/：API路由，包括ai_actions.rs（AI操作）、其他API
  - src/core/：核心逻辑
  - src/models/：数据模型
  - src/ws/：WebSocket实现
  - src/utils/：工具函数
- 数据库迁移：migrations/文件夹下有SQL脚本，如001_initial_schema.sql
- 运行方式：使用cargo run启动服务器

## 前端讲解（Vue.js）
- 前端位于frontend/文件夹，使用package.json管理依赖。
- 技术栈：Vue 3 + TypeScript + Vite
- 主要结构：
  - src/App.vue：主应用组件
  - src/views/：页面视图
  - src/components/：可复用组件
  - src/store/：状态管理
  - src/router/：路由配置
  - src/api/：前端API调用
- 构建工具：Vite，支持热重载
- 运行方式：npm install && npm run dev

## 数据库讲解（PostgreSQL）
- 使用PostgreSQL作为数据库，support/文件夹包含数据库二进制文件。
- 迁移脚本：backend/migrations/和newnewnew/migrations/
- 配置：pg_hba.conf、postgresql.conf等
- 启动数据库：运行support/bin/下的PostgreSQL服务

## AI功能讲解
- AI集成文档：docs/AI功能重构开发文档.md、docs/AI_Markdown输出适配开发文档.md
- 支持AI模型调用，用于智能问答和内容生成
- 权限控制：AI权限操作功能说明.md
- 模型文件：model/文件夹下有相关资源

## 演示步骤
演示将从管理员用户开始，逐步展示系统的核心功能。顺序为：环境准备 → 启动服务 → 登录 → 人员管理 → 班级管理 → AI功能 → WebSocket演示 → 代码展示。

1. **环境准备**：
   - 解说词：“首先，我们需要准备演示环境。确保您的机器上已经安装了Rust编程语言、Node.js运行时和PostgreSQL数据库。如果没有安装，可以从官方网站下载并安装。接下来，克隆这个项目仓库到本地工作目录。”
   - 操作：确保安装了Rust、Node.js、PostgreSQL；克隆项目到本地。

2. **启动数据库**：
   - 解说词：“现在我们启动数据库。这个项目使用PostgreSQL作为后端数据库。进入support文件夹，这里包含了PostgreSQL的二进制文件。我们将运行数据库服务，并执行迁移脚本来创建必要的表结构。”
   - 操作：进入support/文件夹，运行PostgreSQL服务；执行迁移脚本创建表结构。

3. **启动后端**：
   - 解说词：“接下来启动后端服务。后端是用Rust编写的，使用Actix-web框架提供API接口。进入backend文件夹，运行cargo run命令启动服务器。服务器将在localhost的8080端口运行。”
   - 操作：进入backend/文件夹；运行cargo run；确认服务器在localhost:8080启动。

4. **启动前端**：
   - 解说词：“现在启动前端应用。前端是用Vue.js和TypeScript构建的，使用Vite作为构建工具。进入frontend文件夹，先安装依赖，然后运行开发服务器。前端将在localhost的3000端口运行。”
   - 操作：进入frontend/文件夹；运行npm install && npm run dev；确认前端在localhost:3000运行。

5. **功能演示 - 登录**：
   - 解说词：“服务都启动后，我们开始功能演示。首先是登录功能。打开浏览器访问localhost:3000，进入登录页面。我们将使用管理员账号登录系统。管理员拥有所有权限，可以管理用户、班级和AI功能。”
   - 操作：打开浏览器访问前端页面；输入管理员用户名和密码登录。

6. **功能演示 - 人员管理**：
   - 解说词：“登录成功后，我们进入人员管理模块。这里可以添加、编辑和删除用户。我们将演示添加一个新用户，包括设置用户名、密码和角色。注意，系统支持不同的用户角色，如教师、学生等。”
   - 操作：导航到人员管理页面；添加新用户；展示用户列表。

7. **功能演示 - 班级管理**：
   - 解说词：“接下来是班级管理模块。我们可以创建新的班级，并将人员分配到班级中。首先创建班级，设置班级名称和描述，然后从人员列表中选择成员分配到班级。这体现了系统的组织管理功能。”
   - 操作：导航到班级管理页面；创建新班级；分配人员到班级；展示班级详情。

8. **功能演示 - AI功能**：
   - 解说词：“现在演示AI功能。这个系统集成了AI模型，支持智能问答和内容生成。在AI页面，我们可以输入问题，系统会调用AI模型生成响应。注意，AI功能需要有效的API密钥，并且支持Markdown格式输出。”
   - 操作：导航到AI功能页面；输入一个问题；查看AI响应；展示Markdown渲染。

9. **功能演示 - WebSocket实时通信**：
   - 解说词：“最后演示WebSocket功能，用于实时通信。比如聊天室或通知系统。我们将打开两个浏览器窗口，模拟用户之间的实时消息传递。这展示了系统的实时交互能力。”
   - 操作：打开多个浏览器窗口；发送消息；观察实时更新。

10. **代码展示**：
    - 解说词：“演示结束后，我们来看看关键代码。首先是后端的AI操作代码，在backend/src/api/ai_actions.rs中，这里处理AI请求和响应。然后是前端的页面组件，比如人员管理页面，展示Vue.js的实现。”
    - 操作：展示backend/src/api/ai_actions.rs中的AI操作代码；展示前端src/views/下的相关页面代码。
