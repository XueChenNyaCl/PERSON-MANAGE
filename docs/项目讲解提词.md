这是我开发的一个 **智联校园多维管理平台**，也可以理解为一个 **学校综合管理系统**。（停顿）
它主要用于更高效地实现 **校园人员管理**、**班级与日常事务管理**，同时也支持 **AI 辅助操作**。（强调）
下面我来演示一下具体操作。

首先，我们进入 **登录页面**，输入 **管理员账号** 登录。（停顿）
进入系统后，会默认停留在 **仪表盘**。仪表盘会展示一些基础信息，比如 **人数统计**、**公告内容概览**，以及系统的整体运行情况。

接下来，在侧边栏进入 **人员列表**，添加一个老师、学生，或者其他系统人员。（停顿）
输入姓名、性别等基本信息后点击 **保存**，就可以在人员列表中看到刚刚添加的人员。

这些老师或学生在创建时，会默认带有一些权限；不同身份，对应权限也不一样。（强调）
在侧边栏最下方可以查看权限入口；相关权限可参考对应权限文档，然后输入权限名称并添加，这个人员就具备相应操作权限。

另外，也可以直接使用现有的 **权限模板**。权限模板支持 **覆盖** 或 **合并** 权限，能够提高初始化配置效率。

然后我们退出管理员账号，使用刚刚新增人员的 **学号/工号** 作为账户名，输入默认密码登录。（停顿）
登录后可以看到，该人员的界面会根据其权限展示不同功能菜单，实现 **按角色显示、按权限开放**。

如果该人员是 **学生**，通常只能看到 **AI 对话、班级相关信息、通知列表、小组管理** 等板块，且不能修改其他管理模块内容。
如果该人员是 **老师**，则会看到更多功能菜单，例如与 **考勤、评分、通知发布** 相关的功能，并具备部分模块的编辑权限。（强调“部分模块”）

对于 AI 功能，每位人员默认都可以使用 **AI 对话**。（停顿）
AI 对话支持通过自然语言操作系统，比如说：**“帮我创建一个新的考勤记录。”** 或者 **“帮我查看某个班级的通知情况。”**

最后我简要说明一下 **设计思路** 和 **设计过程**：

第一，采用“**权限驱动功能显示**”的设计原则，不同角色看到不同菜单，确保系统遵循最小权限原则。

第二，在业务设计上，围绕 **人员管理、班级管理、考勤管理、评分管理、通知管理** 等校园核心场景进行模块化组织，保证系统结构清晰、便于扩展。

第三，采用“**模板 + 单项权限**”结合的方式，既保证灵活性，也提升了批量配置效率。

第四，AI 能力接入遵循“**自然语言输入 -> 意图解析 -> 权限校验 -> 执行反馈**”的流程，重点保证可用性与安全性。

第五，技术实现上采用 **前后端分离架构**：前端使用 **Vue 3 + TypeScript + Vite**，后端使用 **Rust**，数据库使用 **PostgreSQL**的开发环境进行开发，方便实时更改页面元素和构建稳定的可运行程序。在发布的时候将前端页面构建为静态页面交给后端服务托管，精简了程序内容和部署费用（强调技术亮点）

第六，整体实现上优先保证核心链路：**登录认证 -> 人员管理 -> 权限分配 -> 角色验证 -> 业务操作 -> AI 辅助闭环**，再逐步完善体验细节。
