# 班级权限修复与在线对话开发清单

## 一、需求确认

### 1. 已确认业务口径
- 高中的“级部”按 `高一 / 高二 / 高三` 处理。
- 学生允许查看自己所在班级。
- 家长仅允许查看自己孩子所在班级及对应小组。
- 在线对话窗口默认生成，用户进入页面后直接选择窗口即可聊天。

### 2. 聊天对象默认规则
#### 学生
- 默认加载本班所有老师的对话窗口。
- 默认加载本班所有同学的对话窗口。
- 不允许跨班学生聊天。

#### 老师
- 默认加载自己负责班级学生的对话窗口。

#### 家长
- 当前版本暂不开放聊天。

#### 特定权限用户
- 后续可通过权限扩展聊天范围。

---

## 二、开发总目标

### 1. 班级功能修复
- 修复新增班级时无法正常选择年级的问题。
- 扩展年级选项，支持 `高一 / 高二 / 高三`。

### 2. 班级/小组权限修复
- 修复班级列表和小组列表越权查看问题。
- 教师、学生、家长仅能查看自己有权访问的班级及小组。

### 3. 新增在线对话功能
- 新增默认会话列表。
- 新增聊天消息收发。
- 新增实时聊天能力。
- 不支持好友系统和手动创建对话。
